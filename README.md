# opt-hugo

### Run the following command to install necessary dependencies:

```bash
# instal deps
npm install
```

## Start Hugo

```bash
# server
npm run dev
# build
npm run build
```

### Основной конфиг `config/_default/config.toml`

В нем параметры, меню.

### Конфиг главной `data/home.yml`

В нем секции главной.

### Контент `content/`

Весь контент лежит тут, все по структуре, продукты, услуги, блог и др. стр.

Картинки тянуться из `static/images`.

В остальном все по стандарту hugo, контент можно добавлять по аналогии текущих файлов.
